## Request a direction

After the transaction is confirmed on the relevant public chain, open a GitHub issue containing:

1. the asset and network;
2. the public transaction hash; and
3. the specific feature, test, documentation area, or project direction you want expanded.

The first GitHub issue that claims an unclaimed confirmed inbound transaction hash is accepted as the request attribution for that transaction. This is an operational first-claim rule, not cryptographic proof that the claimant controlled the sending wallet. A hash already attributed to an earlier issue cannot be reused.

The donation can direct what additional work is requested, but it does not purchase ownership, financial returns, a delivery deadline, or acceptance of unsafe, illegal, proprietary, or out-of-scope work. Confirmed funding and completed work are reported factually; projections are not counted as income.
